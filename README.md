# Caderno de sorvetes proteicos — Ninja CREAMi

Receitas de sorvete proteico para a Ninja CREAMi (pote de 473 ml), feitas para **substituir refeições**: todas levam **60 g de whey por pote**, são preparadas no liquidificador, sem fogão, e processadas em `SORVETE LIGHT`.
