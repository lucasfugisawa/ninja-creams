# Caderno de receitas — Ninja CREAMi

Receitas para a Ninja CREAMi (pote de 473 ml): sorvetes, sorbets, gelatos e afins. Toda receita traz a estimativa de **calorias, proteína, carboidratos, gorduras e fibras por pote**, para facilitar a escolha. Várias são proteicas, feitas com whey.

> As informações nutricionais são **estimativas** e não substituem a orientação de um nutricionista ou médico.

## Antes de começar

- **Equipamento:** as receitas foram pensadas para a Ninja CREAMi com pote de 473 ml. Em outro modelo, com pote de outro tamanho, ajuste as quantidades na mesma proporção e use o programa equivalente.
- **Medidas:** colheres medidoras padrão, sempre rasas (chá = 5 ml; sopa = 15 ml).
- **Whey:** as receitas proteicas usam um whey específico. Com outro, veja [Usando outro whey](guia/ingredientes.md#usando-outro-whey).
